# Markcraft Studio 1.2

Professional desktop application for creating editable vector logos and brand identity packages.

Built for people who need high-quality logos without being illustrators. Local-first. Zero cloud. Zero paid dependencies.

## Quick start (development)

```bat
npm install
npm start
```

## Production installer

```bat
scripts\BUILD-INSTALLER.bat
```

This produces:

```
release-installer\Markcraft-Studio-Setup-1.2.0.exe
```

The installer works on Windows 10 / 11 (and Windows 8.1 with the pinned Electron 22 runtime).

## Features

- **Concept gallery** — 4 fully composed logos per round; click one to open it, ♥ to favourite, "More like this" to explore variations, "Generate 4 more" for fresh rounds (never repeats)
- **Layered logo engine** — backdrop layer + frame + multi-part icon + optional second symbol + ornaments, with measured typography (the mark can never cover the name)
- **7 layouts** — stacked, horizontal, circular badge (text on a curve), ribbon emblem, monogram, wordmark (5 name stylings)
- **Finishes** — flat, gradient + gloss, 3D extruded, embossed; metallic accents
- **55 hand-built layered icons**, 10 frame shapes, 7 backdrops, laurel / ticks / stars ornaments, matched to 30 industries and 8 personalities
- System font selection (no paid fonts)
- RGB + CMYK colour tools with live preview
- Colour harmony helpers (complement, analogous, triad, mono)
- Linear / radial gradients on marks
- Clean SVG export (Illustrator / Affinity / Inkscape / Figma ready)
- High-resolution PNG export
- Brand package (SVG + PNG + guidelines with CMYK values)
- Light / Dark / System themes
- Preferences + About
- Local project save/load, autosave + restore, undo / redo (Ctrl+Z / Ctrl+Y)
- Tight-cropped SVG / PNG export, copy SVG to clipboard
- Quality gate before export
